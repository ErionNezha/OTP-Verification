# OTP Verification & Generator

Dy projekte OTP në HTML/CSS/JS: faqe verifikimi me 4 shifra + gjenerues OTP me kopjim në clipboard.

`HTML` `CSS` `JavaScript`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/OTP-Verification/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Hap `demo/index.html` për verifikimin ose `demo/otp-generator/index.html` për gjeneruesin.
